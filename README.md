# Трекер задач (Task Tracker API)


Корпоративный трекер задач с поддержкой пользователей, проектов и задач. Реализовано на FastAPI с асинхронной работой с БД.


## Технологии

* **FastAPI** — фреймворк для создания API;
* **SQLAlchemy** (Async) — ORM для работы с БД;
* **Alembic** — миграции БД;
* **Pydantic** — валидация данных;
* **SQLite** (в памяти для тестов) — база данных;
* **pytest** — тестирование;
* **HTTPX** — HTTP‑клиент для тестов.

## Функциональность


* CRUD‑операции для пользователей, проектов и задач;
* фильтрация и пагинация задач по статусу;
* валидация данных через Pydantic‑схемы;
* автоматическая документация API (Swagger/OpenAPI);
* миграции Alembic;
* покрытие тестами > 60 %.
